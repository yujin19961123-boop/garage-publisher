## 内部 Hash 路由适配修复（2026-11-11，仅本地）

`backend/hash_routes_test.go` 使用 Node 执行适配后的脚本，覆盖路由表与 Hash 编解码往返、动态图片、无扩展名资源、有点号的业务路由、真实导航地址及幂等处理。后端全量测试在本地 `TEST_DATABASE_URL` 下通过，包含隔离 schema 的数据库测试；`go vet` 通过。
