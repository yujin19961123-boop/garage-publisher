# 删除项目

项目所有者可从项目详情底部点击“删除项目”，在同一弹窗确认后永久删除。管理员不能删除其他成员项目。

删除结果：

- 项目从管理列表和公开合集中移除。
- 原项目链接返回404，且不会重新分配给之后创建的同名项目。
- 项目发布记录与产物被清理，保留删除操作审计。
- 上传或发布进行中时拒绝删除，避免与发布任务交错。

接口 `DELETE /api/v1/projects/{id}` 使用现有会话和CSRF验证。事务内锁定项目、检查所有权与进行中任务，保留已删除公开标识，记录清理任务后删除项目数据。文件清理发生在事务提交后；失败的清理任务由Worker重试，项目不会重新对外可见。

文件清理只接受服务端生成的48位十六进制ID，对数据目录下精确目标进行边界与链接检查，不递归删除整个数据目录。此功能不提供恢复或回收站。

验收脚本：

```powershell
$env:TEST_PORT='8080'
node scripts/test-delete-project.mjs
```

脚本只删除自己创建的测试项目。会创建一个带delete_test前缀的测试账号，账号信息记录在 `.local/delete-test-account.json`，验收后应单独清理该测试账号。
