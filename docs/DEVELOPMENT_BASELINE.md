2026-11-10 路径兼容修复：取消对HTML根路径/assets的直接拒绝，发布到私有处理中目录后自动适配本地HTML、CSS、JS资源和常见根导航。对JS使用语法树，仅修改可识别字符串/模板和模块地址，保留正则与外域。用户不再需要配置base或HashRouter来解决此类资源引用；框架任意路由逻辑不作通用修复保证。适配成功后仍以原子切换上线。

2026-11-10 上传方式：创建和更新均接受整个dist文件夹、拖入dist内全部文件与子文件夹、多选文件、单个ZIP。客户端保留相对目录并自动打包，服务端在安全解压后识别并剥离唯一外层文件夹，支持ZIP直接含首页或包有dist外层；无需用户自行整理压缩结构。缺少唯一首页、多个独立原型混放或非法内容时明确提示。原型的相对资源路径约定不变。

2026-11-10 项目说明字段已取消：创建与编辑只保留项目名称，创建弹窗同时选择ZIP并发布；列表和合集不展示说明。数据库与API不再保存或返回项目说明。

2026-11-10 创建项目交互：一个弹窗填写名称、说明和ZIP，点击“创建并发布”，在同一弹窗查看上传进度、发布结果并复制链接。文件格式、非空和大小在创建记录前校验；发布失败后重试复用项目，不重复创建。处理期间禁用重复提交，完成后刷新项目列表。

2026-11-10 地址命名调整：新项目以中文名称拼音或英文名称生成分享路径，重名先尝试111、222等重复数字，再尝试其他不超过三位的数字。数据库唯一约束处理并发重名；用尽候选后提示更换名称。名称修改不改变链接，旧随机地址继续有效。生产原型采用 byjin.cn/<slug>/，后台为 console.byjin.cn；证书覆盖这两个主机名即可，新项目不增加证书。产物使用相对资源路径与hash路由。

2026-11-10 页面简化：登录和列表不显示编译、路由、预分配地址等术语；未发布项目只提示下一步上传，成功后显示分享链接。打包方法折叠在“文件怎么准备？”内，必要文件名保留并解释。发布进度与错误采用日常说法；成员密码仍至少6位、可纯数字。

## 产品范围

管理员开通、停用成员及重置密码；成员登录、创建项目、修改自己的项目、上传 ZIP、查看发布状态、复制固定链接、原地址更新。管理员可查看全部项目，但不能修改或发布他人项目。查看原型无需登录。停用成员不下线已发布原型。

不实现公开注册、在线编辑或构建、后端应用托管、Git 发布、历史版本界面、回滚、自定义域名、协作和付费。

## 技术决策

- 前端：React、TypeScript、Vite。
- 服务：Go，PostgreSQL 保存账号、会话、项目和任务；文件存于持久化目录。
- 部署：Docker Compose，Nginx 入口。开发允许直接运行 Go 与 Vite。
- 原型地址：项目名拼音对应固定路径。本地为 `http://localhost:8080/<slug>/`，后台为 `http://console.localhost:8080/`；旧随机子域名链接保留。
- 生产后台 console.byjin.cn 与原型 byjin.cn 分开主机名和登录Cookie；项目之间共享原型站点的浏览器源，不隔离LocalStorage。
- 发布目录不可变，以数据库 `current_release_id` 作为唯一线上指向；准备完新目录后用事务切换，不覆盖旧目录。
- Worker 与 API 可在同一 Go 进程中运行，通过数据库持久任务与唯一约束协调，降低单机 MVP 运维成本。
- 静态文件由 Go 校验 Host、发布指向与路径后流式发送，经 Nginx 反向代理；初期不使用 X-Accel-Redirect，减少网关与 Nginx 路径编码不一致风险。
- 所有原型响应禁止缓存；不保证已打开旧页面跨发布的多个请求都使用同一版本。不支持 Service Worker/PWA 缓存行为。

## 发布约定

ZIP 根目录必须含普通文件 `index.html`，不自动剥离 `dist/` 外层，不构建源码。普通静态模式按实际文件访问；SPA 模式仅对页面导航回退根 HTML，缺失资源仍返回 404。

目标限制：上传 100 MiB，解压 500 MiB，单文件 100 MiB，10,000 个条目，目录深度 20。必须以实际流量/解压字节计数，不信任 ZIP 声明大小。拒绝越界路径、符号链接、特殊文件及重复路径。

## 核心数据与接口

账号、会话、项目、发布任务和发布产物分别建模。项目状态由是否有线上发布得出，任务失败不改变项目已有发布状态和成功时间。管理 API 统一 `/api/v1`。以服务端会话 Cookie 登录，写请求使用 CSRF Token。项目写操作必须校验所有者。

## 验收清单

- [ ] 新成员可独立登录、创建项目和发布 ZIP。
- [ ] 匿名浏览器能打开多页面、图片、CSS 和 JavaScript。
- [ ] SPA 子路由刷新正常，缺失 JS 不返回 HTML。
- [ ] 更新沿用原链接；新版删除的文件不会从旧目录回退。
- [ ] 非法 ZIP、缺入口、解压失败和超限均不改变旧版。
- [ ] 同项目并发发布被拒绝；中断任务可恢复或安全失败。
- [ ] 成员不能访问他人的管理任务或覆盖他人项目。
- [ ] 管理员对他人项目只读。
- [ ] 停用、重置密码撤销会话；停用不撤销当前原型。
- [ ] 启动文档、配置样例、必要自动化测试齐备。

## 上线前确认

公司允许上传的信息范围、真实容量、服务器资源、后台与原型域名、证书自动续期、备份与恢复演练、告警和运维负责人。单机故障不保证可用；链接不是访问控制，不能存放真实敏感数据或账号密钥。

## 发布交互调整
发布入口不再展示路由模式，默认采用实际文件优先、HTML页面导航回退根入口的兼容策略。普通多页面按实际文件访问；缺失资源仍返回404。后端保留显式static选项供技术调用，但产品界面不要求用户判断。
