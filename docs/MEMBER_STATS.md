# 成员使用统计

管理员在“成员”列表查看每个账号的占用空间、登录次数及最近登录时间，点击“刷新”重新读取。成员账号不能访问统计接口。

## 统计口径

- **占用空间**：该成员项目当前实际存在的文件大小合计，包含当前与历史版本、完整性清单、上传中的 ZIP/分片、解压暂存和失败任务残留。已删除项目仍有待清理文件时继续归属原成员，文件清理后减少；版本切换不增加占用。不是历史上传量累加。
- 大小以 B / KB / MB / GB 显示（1000进制）。不分摊共享数据库、服务器日志、容器镜像或备份，也不包含文件系统分配块及目录元数据开销，因此不是整台主机 `df` / `du` 的占用总和。
- **登录次数**：只累计成功创建并提交登录会话的次数。错误密码、停用账号、会话写入失败、刷新页面和复用已有登录态均不增加。并发登录原子递增。
- **最近登录**：最近一次成功登录的时间，使用与项目相同的相对时间显示，悬浮展示完整日期时间。

此前没有保存完整登录历史，不能准确恢复过去次数。本功能迁移时为已有账号记录 `login_stats_since`，从0开始累计；旧会话不冒充新登录，没有可用时间时显示“暂无记录”，不是“从未登录”。列表下方说明统计起点，登录次数悬浮可查看该账号开始统计的具体时间。

## 实现和异常

`GET /api/v1/admin/users` 保留原账号字段，并增加：

```json
{
  "items": [{
    "id": "…", "username": "…", "role": "member", "status": "active",
    "storageBytes": 13900000,
    "loginCount": 2,
    "lastLoginAt": "2026-11-10T12:00:00Z",
    "loginStatsSince": "2026-11-10T11:00:00Z"
  }],
  "storageMeasuredAt": "2026-11-10T12:01:00Z"
}
```

登录计数、最近登录及会话插入位于同一事务，更新账号时再次检查启用状态和认证版本，配合账号停用和密码重置的锁。字段持久化保存在 PostgreSQL，服务重启或重复迁移不清零。初始化账号不会计作登录。

占用统计在读取一致的项目所有权快照后扫描本平台数据目录，归属项目创建者。删除任务记录所有者，旧任务通过删除审计补全归属。扫描不跟随符号链接，不修改上传或版本文件；常规刷新只读，文件系统扫描预算5秒。发布、重命名或清理期间文件持续变化，读数可能短暂波动。无法完整读取或超时时 `storageBytes` 与 `storageMeasuredAt` 返回 `null`，显示“暂不可用”，仍返回登录统计；不将部分结果误报为0。读取接口失败则保留已显示列表，并允许刷新重试。

桌面使用七列表格，手机按成员分卡展示，避免横向拖动才能查看数据。启用、停用、重置密码及管理员自身限制沿用原有权限。

## 本地验证

```powershell
# 前端模拟：所有 API 被拦截，不操作账号或项目。
node scripts/test-member-stats-ui.mjs

# 真实本地账号与 ZIP：创建并清理唯一临时项目，不新增账号。
node scripts/test-member-stats-local.mjs
```

后端 `TestMember...` 测试覆盖文件归属、保留版本与暂存文件、清理后减少、取消、异常路径、符号链接拒绝（系统允许创建链接时）、成功/失败/并发登录、会话事务失败回滚、重启迁移保留统计、管理员权限和旧清理任务归属补全。数据库用例复用 [版本测试的隔离 fixture](VERSIONS.md)，仅接受本地 `TEST_DATABASE_URL`，创建并清理随机 schema，不操作现有业务表。

本次前端构建、带本地数据库的后端全量测试、`go vet`、浏览器模拟界面及真实 ZIP 核对均已通过。真实测试验证两次上传的保留文件字节与成员空间增量一致，原链接显示新版；删除临时项目后空间回到基线，其他项目和当前版本未变。测试报告 `.local/member-stats-local-report.json` 的 `success` / `cleanup` 均为 `true`。本地服务已加载新功能；2026-11-10 经用户明确授权后已同步上线并通过真实 ZIP 与成员统计检查，见[生产发布记录](PRODUCTION_GARAGE.md)。
