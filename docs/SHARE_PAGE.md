# 全部原型分享

## 需求结论

用户确认只需将自己全部项目放到一个分享页面，本期不引入产品分组、项目归属选择或协作权限。

- 项目列表增加“分享全部原型”入口。
- 每个账号拥有一个固定合集地址，可复制和打开，查看者无需登录。
- 页面仅展示该账号已成功发布的项目：名称、最近成功发布时间及原型链接。
- 未发布项目和其他成员的项目不得出现在页面或HTML源码中。
- 后续新增发布、名称修改和更新在原合集链接中即时反映；失败更新仍展示原有可用项目。
- 管理员分享的也是自己的项目，不能聚合全平台其他成员项目。
- 暂无发布内容时显示空态，后续发布自动加入。
- 停用账号不下线已经发布的原型，因此已创建的合集也保持可访问。

## 实现约定

单项目分享保留。合集使用独立保留路径 `/_share/<账号分享标识>/`，避免与项目拼音路径冲突；账号只生成一次标识，按账号名转换并沿用短数字去重规则。

管理接口 `POST /api/v1/share-page` 验证登录与CSRF，幂等返回 `{url,publishedCount}`。合集元数据保存在新增 `share_pages` 表，不改变已有账号、项目和发布记录。

匿名页面由后端生成，HTML模板转义名称，不注入上传的HTML、不嵌入原型脚本。响应不缓存，查询失败不伪装为空合集。链接依然可被转发，不增加密码或访问控制选项。

## 验证

启动本地服务后，在根目录运行：

```powershell
$env:TEST_PORT='8080'
node scripts/test-share-page.mjs
```

覆盖账号隔离、管理员边界、未发布隐藏、匿名访问、幂等并发、实时名称更新、后续新增、失败发布、HTML转义、HEAD和错误路由。
